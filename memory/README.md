# Procedural Memory

This directory stores reusable operating knowledge compiled from observed outcomes.

Memory is not a substitute for evidence. Every promoted lesson should point to receipts or source evidence.

## Classes

- `rules/` — reusable procedures that repeatedly help under declared scope.
- `anti-patterns/` — repeated harmful or misleading procedures.
- `negative-memos/` — known non-applicability or refutation conditions that prevent repeated dead-end work.
- `workflows/` — multi-step reusable procedures promoted from repeated successful execution.

## Promotion rule

```text
observation
→ candidate lesson
→ supporting evidence
→ repeated/shadow use
→ promoted procedural memory
```

Harmful evidence lowers confidence faster than helpful evidence raises it. Stale lessons must retain scope and invalidators rather than becoming timeless truths.
